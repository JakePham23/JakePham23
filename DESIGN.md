# Design System: Jake Pham - Antigravity Portfolio
**Project ID:** `jakepham-portfolio-v2`

## 1. Visual Theme & Atmosphere
The design system adopts a **"Weightless Cyber-Spatial Dark Mode"** aesthetic. The atmosphere feels deep, futuristic, yet clean and highly readable. It leverages glassmorphic translucency, ambient glowing highlights, and spatial depth (Z-layering) to elevate Jake Pham's identity as a Data Engineer & SOTA AI Developer.

## 2. Color Palette & Roles

* **Deep Cosmic Obsidian (`#0F172A`)**: Primary background canvas, providing high-contrast depth.
* **Glassmorphic Slate (`#1E293B`)**: Container cards, elevated with semi-translucency and backdrop blur.
* **Electric Cyber Cyan (`#38BDF8`)**: Primary brand accent, used for headers, key badges, and focus links.
* **Emerald Neural Green (`#34D399`)**: Metrics, real-time performance indicators, and active status.
* **Neon Violet AI Accent (`#A855F7`)**: Used specifically for Graph-RAG, Knowledge Graph, and LLM Agent highlights.
* **Muted Silver Text (`#94A3B8`)**: Secondary copy and technical metadata for smooth scannability.

## 3. Typography Rules

* **Header Font:** `Fira Code` / `JetBrains Mono` — Monospaced, technical, clean, and crisp.
* **Body Font:** System UI / `Inter` — High legibility across all screen densities.
* **Hierarchy & Weight:** Bold headers (`700`), semi-bold sub-headings (`600`), regular body (`400`), uppercase badges (`500`).

## 4. Component Stylings

* **Floating Glass Cards:** Soft diffused drop-shadows (`box-shadow: 0 20px 40px rgba(0,0,0,0.3)`), subtle 1px border (`rgba(255,255,255,0.1)`), and floating Y-offset.
* **Isometric Architecture Diagrams:** Styled ASCII blocks with clear directional vectors (`──>`, `│`, `┌──┐`) representing real-time data flow and Graph-RAG pipelines.
* **Badges & Pill Tags:** Pill-shaped (`rounded-full`), dark-tint background with vibrant text and glowing borders.
* **Metrics Highlight Cards:** Compact, high-contrast key-value pairs formatted with emoji cues and quantitative metrics.

## 5. Layout Principles

* **Z-Axis Elevation:** Foreground cards float over deep dark backgrounds with generous vertical spacing (32px-48px).
* **Grid Alignment:** Two-column split for skills and stats, balanced single-column layout for deep project breakdowns.
* **Spatial Rhythm:** Clean horizontal rules (`---`) with gradient glows separating core narrative zones.
